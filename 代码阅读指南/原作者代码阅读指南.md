# 代码阅读路线图

## 调用关系

**训练：** `train_pl.py → DataModule → ForeverTaskDataset → FeaturizePocket / FeaturizeMol → 任务 transform → noiser → 拼批 → PMAsymDenoiser → loss`。加噪发生在拼批前，模型预测干净变量。

**采样：** `sample_use.py → 输入解析 → UseDataset → featurizer → 任务 transform → 拼批 → sample_loop3 → 拆批 → decode_output → 分子重建与保存`。每步采样执行 `noiser(batch, step) → model(batch) → noiser.outputs2batch(batch, outputs)`。

**网络：** 原子/键类别嵌入与固定提示拼接 → 口袋编码 → 配体内部及配体—口袋消息传递 → 节点、边、坐标更新 → 预测头。默认口袋编码器和配体骨干均为 `ContextNodeEdgeNet`；口袋坐标固定，配体—口袋近邻随配体坐标重新构建。网络不直接读取任务名称或时间步。

**配置：** [任务示例](../configs/sample/examples/) 提供输入、任务与采样设置；[pxm.yml](../configs/sample/pxm.yml) 指定权重；checkpoint 配套 `train_config` 提供网络结构、词表及 `from_train` 噪声先验。[train_pxm_reduced.yml](../configs/train/train_pxm_reduced.yml) 是仓库提供的联合训练示例配置。

## 主要字段

`N`、`H`、`P` 分别为批次内配体原子、配体半边、口袋原子的总数。单分子有 `n` 个原子时，半边数为 `n(n-1)/2`，包含无键原子对；不同分子之间没有半边。

| 字段 | 形状与含义 |
|---|---|
| `node_type`、`node_pos` | `(N,)` 原子类别编号、`(N,3)` XYZ 坐标；训练时为干净目标，采样时为当前状态 |
| `halfedge_index`、`halfedge_type` | `(2,H)` 原子对索引、`(H,)` 键类别；`0` 为无键，`1/2/3/4` 为单/双/三/芳香键 |
| `pocket_pos`、`pocket_atom_feature` | `(P,3)` 口袋坐标、当前实现 `(P,25)` 特征；后者由元素、20 类氨基酸及主链标记组成 |
| `pocket_center` | 单样本通常为 `(1,3)`；口袋与配体共同减去的坐标中心，导出时加回 |
| `fixed_node / fixed_pos`、`fixed_halfedge / fixed_halfdist` | 长度分别为 `N`、`H` 的 0/1 提示；依次表示原子类别、坐标、键类别、原子对距离是否已知，`1` 为已知 |
| `node_in / pos_in / halfedge_in` | 本步带噪输入；形状与对应分子状态一致 |
| `pred_node / pred_pos / pred_halfedge` | 原子类别分数、坐标、半边类别分数；类别输出还有词表维度，尚未归一化 |
| `node_type_batch / halfedge_type_batch / pocket_pos_batch` | 每个配体原子、半边或口袋原子所属的图编号，如 `[0,0,1]` |

坐标单位为 Å。`node_type` 按配置元素表编码，例如 reduced 配置中碳为 `0`；它不是原子序数。半边在网络内部复制为正反两条边，输出前合并。原子类别和半边类别各有独立的 mask 类，表示待恢复类别。

## 任务实现

`task.name` 是任务标签，`task.transform.name` 和 `noise.name` 分别选择变换与噪声器，三者可以不同。

| 任务 | 主要实现与变量设置 |
|---|---|
| 构象生成 `conf`、对接 `dock` | 共用 `ConfTransform`；噪声器为 `ConfSampleNoiser`、其子类 `DockSamplNoiser`。给定原子与键，恢复坐标；构象生成无口袋 |
| `dock + free` | `fixed_node=1`、`fixed_pos=0`、`fixed_halfedge=1`、`fixed_halfdist=0`；逐原子坐标加噪，无额外后处理时直接写回 `pred_pos`，保留输入原子和键 |
| 无口袋生成 `denovo`、口袋分子设计 `sbdd` | 基础实现为 `DenovoTransform`、`DenovoSampleNoiser / SBDDSamplNoiser`；原子类别、键和坐标均待生成 |
| 片段补全、连接、生长 | `MaskfillTransform / MaskfillSampleNoiser` 按已知与生成部分分区；`LinkingTransform`、`GrowingTransform` 处理相应预设片段 |
| 分阶段生成 | `AutoregressiveTransform` 等逐轮更新已知部分和待生成部分；例如 `sbdd.yml` 使用 `ar` transform 与 `maskfill` noiser |
| 肽设计 `pepdesign` | `PepdesignTransform / PepdesignSampleNoiser` 区分主链与侧链，并设置各自固定条件与噪声 |
| 自定义任务 `custom` | `CustomTransform / CustomSampleNoiser` 用 `partition` 划分原子，通过 `prior/level/mapper` 指定分区变量的噪声 |

## 输出与评测

- 用户输入采样的最终结构保存在运行目录下的 `运行目录名_SDF/`，轨迹保存在 `SDF/`；`gen_info.csv` 记录候选标识、文件名、重建标签与置信度。
- [evaluate_dock.py](../evaluate/evaluate_dock.py) 使用不移动配体的 `CalcRMS` 计算 docking 误差；[evaluate_conf.py](../evaluate/evaluate_conf.py) 使用允许刚体对齐的 `GetBestRMS` 计算内部构象差异。
- `get_cfd_traj` 在普通采样中对原子及后半段步骤的原始位置置信度求平均；`rank_pose.py` 的 `self_ranking` 再加碰撞、立体化学检查各一个 0/1 分数。置信度不等于 RMSD 或结合亲和力。
- 详细字段与调用说明见 [talk/README.md](../talk/README.md)；安装、采样、训练及数据处理说明见 [docs/README.md](../docs/README.md)。
