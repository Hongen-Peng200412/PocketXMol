## `local_cov` 输入与角色分工

### 受体原子提供 50 维散射特征

`receptor_tokens.npz` 已经保存与受体原子逐项对齐的 `feat` 和 `is_backbone`：

- `feat`：float32，形状为 `(P, 49)`，包含元素、残基类别、理化属性、归一化质量和局部邻居计数等既有特征；
- `is_backbone`：bool，形状为 `(P,)`，表示相应蛋白质或核酸原子是否属于主链。

在模型输入边界把 `is_backbone` 转成 0/1 浮点数并作为第 50 维拼到 `feat` 后面，得到 `receptor_feature_50`，形状为 `(P, 50)`。不新建受体特征资产，不把现有 25 维蛋白特征、15 维核酸特征或 128 维受体图隐藏特征投影为这 50 维输入。

只有当前 C0、C5 或 E 口袋实际选中的 RA 标准受体原子参与散射。散射原子集合与受体图使用的原子集合一致，因此不会通过密度分支扩大受体范围。

### 配体原子读取局部体素

受体原子是 50 维体素特征的提供者；配体原子是 106 维局部体素块的读取者，也是 FiLM 调制的对象。

设一个 batch 包含 $B$ 个实例、$N$ 个配体原子和 $P$ 个已选受体原子：

- `density_input`：形状为 `(B, 56, 80, 80, 80)`，空间轴按 ZYX 排列；
- `receptor_feature_50`：形状为 `(P, 50)`；
- `receptor_batch`：形状为 `(P,)`，指明每个受体原子属于哪个实例；
- `ligand_batch`：形状为 `(N,)`，指明每个配体原子属于哪个实例；
- `density_origin`：形状为 `(B, 3)`，表示实际 80³ 裁块角点在 PocketXMol 模型局部坐标中的 XYZ 位置，单位为 Å；
- `density_basis`：形状为 `(B, 3, 3)`，三行分别是体素 X、Y、Z 轴在模型局部 XYZ 坐标中的步进向量，单位为 Å。

### 连续坐标到 home 体素

对属于实例 $b$、局部 XYZ 坐标为 $x$ 的受体或配体原子，连续体素 XYZ 坐标为：

$$
v=(x-\mathrm{density\_origin}_b)\,\mathrm{density\_basis}_b^{-1}.
$$

home 体素 XYZ 整数坐标为：

$$
j=\lfloor v\rfloor.
$$

写入或读取张量时，把 $j=(j_x,j_y,j_z)$ 重排为 `(j_z, j_y, j_x)`。home 使用 `floor`，不使用四舍五入。坐标映射使用 float32 几何计算，即使卷积训练处于 `bf16-mixed`。

### 106 通道固定体素网格

受体 50 维特征使用硬散射：

- home 位于 80³ 裁块内的受体原子才参与散射；越界受体原子直接忽略，不能把其 home 截断到边界；
- 多个受体原子落入同一体素时逐通道求和，即 `scatter_sum`；
- 不使用均值、三线性软散射、高斯软散射、占据通道或额外有效体素掩码。

由此得到 `receptor_grid`，形状为 `(B, 50, 80, 80, 80)`。它与 `density_input` 沿通道维拼接：

$$
G=\operatorname{concat}(D_{56},R_{50})
\in\mathbb{R}^{B\times106\times80\times80\times80}.
$$

`G` 在一次 PocketXMol 前向中只构造一次，六个去噪块共同读取同一个张量。它不随块内配体坐标更新而改变。

## 11³ 局部块的抽取契约

第 $l$ 个去噪块使用该块节点更新后、坐标更新前的配体坐标 $x_i^{(l)}$ 计算配体原子 $i$ 的 home。每轴读取相对 home 的整数偏移 `-5, -4, ..., 5`，得到：

$$
Q_i^{(l)}\in\mathbb{R}^{106\times11\times11\times11}.
$$

11³ 块始终以实际 home 体素为中心：

- 不把局部块平移到 80³ 裁块内部；
- 不截断或改写配体 home；
- 越过 80³ 边界的局部块位置填 0；
- 不把局部块的有效位置掩码送入卷积编码器；
- 配体 home 完全落在裁块外时仍按相同规则读取，可能得到部分或全部为 0 的 11³ 块。

这里的零填充只属于模型读取 11³ 邻域时的边界定义，不改变“源 80³ 裁块不补零”的数据契约。80³ 裁块只提供更宽的可读边界；局部卷积编码器每次仍只处理当前配体原子的 11³ 邻域。具体抽取行为应复用或等价实现 Pocket_Plus `gather_voxel_cube(..., zero_fill=True)`。

每个去噪块都依据当时的配体坐标重新计算 home 并重新抽取局部块。不能在第一个去噪块计算后把配体 home 或局部块缓存给后续五个块。

## 局部卷积编码器

### 已固定参数

| 参数 | 固定值 | 具体含义 |
| --- | ---: | --- |
| in_channels | 106 | 56 维密度通道与 50 维受体散射通道 |
| cube_size | 11 | 每个配体原子的局部体素块边长 |
| hidden_channels | 64 | 三层三维卷积的输出通道数 |
| num_downsample | 2 | 两层 kernel_size=3, stride=2 的三维卷积 |
| num_regular_conv | 1 | 一层 kernel_size=3, stride=1 的三维卷积 |
| num_groups | 8 | GroupNorm 把 64 个通道分成 8 组，每组 8 个通道 |
| 激活函数 | SiLU | 每层 GroupNorm 后使用的逐元素非线性函数 |
| out_dim | 64 | 全局平均池化和线性投影后的条件向量宽度 |
| chunk_size | 4096 | 一次抽取并卷积的配体原子数；显存不足时只降到 2048 |
| 编码器数目 | 6 | 六个去噪块各自拥有一套独立卷积参数 |
| 输出 LayerNorm | 1 套共享参数 | 六个卷积编码器的 64 维输出共同使用同一套 LayerNorm |

### 选定的顺序卷积结构

编码器采用三层顺序卷积，不增加残差连接、`1×1×1` 捷径卷积或独立空间池化。输入为 `(M, 106, 11, 11, 11)`，其中 $M\leq4096$ 是当前原子分块大小；完整结构固定为：

```text
Conv3d(106 -> 64, kernel=3, stride=2, padding=1, bias=False)
GroupNorm(8, 64)
SiLU
                                                    -> (M, 64, 6, 6, 6)

Conv3d(64 -> 64, kernel=3, stride=2, padding=1, bias=False)
GroupNorm(8, 64)
SiLU
                                                    -> (M, 64, 3, 3, 3)

Conv3d(64 -> 64, kernel=3, stride=1, padding=1, bias=False)
GroupNorm(8, 64)
SiLU
                                                    -> (M, 64, 3, 3, 3)

AdaptiveAvgPool3d(1)  -> (M, 64, 1, 1, 1)
flatten               -> (M, 64)
Linear(64 -> 64)      -> (M, 64)
共享 LayerNorm(64)    -> (M, 64)
```

这一结构采用以下取舍：

- stride-2 卷积承担可学习下采样，不另加最大池化或平均池化；
- 一层 stride-1 卷积在 3³ 尺度继续融合邻近体素；
- 每层卷积之后固定依次执行 GroupNorm 和 SiLU；
- 全局平均池化只在空间尺寸降到 3³ 后执行，因此 27 个末级体素都参与最终条件向量；
- 三层卷积的感受野依次为 3、7、15 个输入体素；第三层已经覆盖完整 11³ 输入，末尾全局平均池化再汇总其 3³ 输出；
- GroupNorm 不依赖训练 batch 大小，适合配体原子数变化和按原子分块的计算方式；
- 卷积层使用 `bias=False`，因为其后紧接带仿射参数的 GroupNorm；最终 `Linear(64,64)` 保留偏置。

除 FiLMPlus 的末层零初始化外，其余卷积、线性层和归一化层沿用 PyTorch 的标准初始化，不增加额外初始化方案。局部卷积中不使用 dropout。

### 六套卷积参数与共享输出归一化

六个去噪块分别拥有 `LocalCubeEncoder[0]` 至 `LocalCubeEncoder[5]`。六套三层卷积、GroupNorm 和最终 `Linear(64,64)` 参数互不共享，使不同深度能够学习不同的密度解释方式。

六套编码器的输出共同通过同一个可学习 `LayerNorm(64)`。共享 LayerNorm 只统一进入 FiLMPlus 前的特征尺度，不使六套卷积参数共享。

## FiLMPlus 注入契约

PocketXMol 当前配体节点隐藏宽度为 320。第 $l$ 个去噪块得到归一化后的局部条件向量 $q_i^{(l)}\in\mathbb{R}^{64}$ 后，使用该块独有的 FiLMPlus：

$$
[\gamma_i^{(l)},\beta_i^{(l)}]
=\operatorname{MLP}_l(q_i^{(l)}),
$$

$$
h_i^{(l)\prime}
=h_i^{(l)}\odot(1+\gamma_i^{(l)})+\beta_i^{(l)}.
$$

其中 $h_i^{(l)}$、$\gamma_i^{(l)}$ 和 $\beta_i^{(l)}$ 的形状均为 `(320,)`。每套生成器采用：

```text
Linear(64 -> 320)
SiLU
Linear(320 -> 640)，权重和偏置均初始化为 0
```

不使用 dropout，不增加独立的 0.1 可学习门控。末层零初始化使新密度分支在初始参数下满足 $\gamma=0$、$\beta=0$，所以共享的 PocketXMol 主体在第一次前向中保持原输出。

现有密度读取接口在 `models/graph_context.py` 中采用“外部再加一个密度残差”的写法。`local_cov` 的 FiLMPlus 已经返回完整的调制后节点特征，因此必须直接赋值：

```python
h_node = film_plus(h_node, local_condition)
```

不能保留以下外加形式：

```python
h_node = h_node + film_plus(h_node, local_condition)
```

否则零初始化时会得到 `2 * h_node`，破坏与无密度官方初始行为的一致性。

密度注入位置保持为：本层配体节点消息更新完成之后、配体边特征和坐标更新之前。边与坐标更新读取已经经过 FiLMPlus 调制的节点特征。

## 激活重计算、分块与批量

### 局部卷积激活重计算

正式训练对六套局部卷积编码器启用激活重计算。每个原子分块的“11³ 抽取、三层卷积及其 GroupNorm 和 SiLU、全局平均池化、线性投影”作为一次可重算计算；反向传播重新执行该部分前向，以减少保存六层卷积激活造成的显存占用。

训练时使用 `torch.utils.checkpoint.checkpoint(..., use_reentrant=False)`；验证和推理不启用激活重计算。局部卷积不含随机层，因此重算不需要引入新的随机数状态。

### 原子分块

- 首选 `chunk_size=4096`。
- 发生局部块或卷积相关的显存不足时，只把 `chunk_size` 降到 2048。
- 分块只改变一次送入卷积的原子数。输出按原配体原子顺序拼回，因此不改变 home、局部块、卷积参数或 FiLMPlus 结果。
- 不尝试 384、128 等其他分块值，不进行分块大小网格搜索。

### 正式训练批量

- 首发配置为单卡 `batch_size=36`、梯度累积 2 次，配置层面的 `global_batch_size=72`。
- 不以 `72×1` 作为首发配置，因为六套 11³ 局部卷积可能接近或超过 80 GiB 显存。
- 若 `chunk_size=2048` 后仍然显存不足，沿现有规则改为 `batch_size=24`、梯度累积 3 次，保持 `global_batch_size=72`。
- 训练继续使用 `bf16-mixed`；正式推理保持官方 FP32 张量路径。

## 必要验收

验收使用非测试样本。验收命令与正式训练、推理和评价命令分别记录。

### 受体特征与硬散射

- 证明 `feat (P,49)`、`is_backbone (P,)`、受体坐标、残基类型和口袋选择掩码逐原子对齐。
- 证明只有选中的 RA 标准蛋白质及核酸原子进入 50 维散射，`UNK` 不进入。
- 使用人工构造的同体素多原子例子证明 50 维特征逐通道求和。
- 与 Pocket_Plus 硬 `scatter_sum` 在相同输入上逐元素比较。
- 证明越界受体原子被忽略，而不是截断到 80³ 边界。

### 坐标、home 与边界

- 使用非单位体素基和非零 `density_origin` 验证 XYZ 连续坐标、`floor` home 及 ZYX 数组索引。
- 使用靠近六个裁块面的配体原子验证 11³ 窗口不移动、越界位置为 0。
- 使用裁块外配体 home 验证不会把 home 截断到边界。
- 验证 C0、C5 和 E 的密度裁块起点变化不改变 PocketXMol 模型原点。
- 验证最终世界坐标只恢复一次。

### 卷积结构与参数关系

- 验证 11³ 依次变为 6³、3³，最终输出为 `(N,64)`。
- 验证每套编码器恰有两层 stride-2 卷积和一层 stride-1 卷积，卷积后均为 GroupNorm 与 SiLU，且不存在残差连接、`1×1×1` 捷径或额外空间池化。
- 验证恰有六套互不共享的局部卷积编码器、一套共享 LayerNorm 和六套互不共享的 FiLMPlus。
- 验证 `chunk_size=4096` 与 2048 在 FP32 评价模式下保持相同原子顺序和数值等价。
- 验证激活重计算开启与关闭时前向输出一致，参数梯度在允许的浮点误差内一致。

### 注入位置与初始等价性

- 验证每层 home 使用该层节点更新后、坐标更新前的配体坐标；配体坐标改变时后续层 home 随之重新计算。
- 验证固定 106 通道网格在六层间为同一科学输入，不被配体坐标更新或 FiLMPlus 原地修改。
- 验证六套 FiLMPlus 末层权重和偏置均为 0。
- 在相同口袋、局部坐标、噪声等级和随机数下，验证新模型初始化时的 T0 输出与无密度主体实质等价。
- 特别验证接线采用直接赋值，不发生 `h_node + film_plus(h_node, cond)` 导致的节点特征加倍。
- 由于零初始化 FiLMPlus 会使局部卷积在第一次反向时暂时收不到有效梯度，GPU 训练验收至少执行两个优化器更新，并证明 FiLMPlus 更新后梯度能够到达六套局部卷积编码器。

### 完整数据路径与 GPU 门控

- 用非测试实例完成 Dataset、collate、受体散射、六层局部读取、loss 和反向传播的完整路径。
- 证明采样器不读取 GT 中心、GT 偏移或测试配体真值坐标来决定 T0 更新公式。
- 在获准 A800 上以 `36×2` 执行短时训练门控，记录峰值显存、每次优化器更新耗时，以及是否需要把 `chunk_size` 从 4096 降到 2048。
- 验证从官方初始参数加载时，原模型参数全部来自规定检查点，六套局部卷积、共享 LayerNorm 和六套 FiLMPlus 是新建参数；不继承第一次密度尝试的训练状态。
- 验证保存和恢复完整检查点时包含优化器、学习率调度器、下降次数及全部 `local_cov` 参数。

正式训练控制固定为：

- AdamW：初始学习率 `1e-4`、`weight_decay=0.001`、`betas=(0.99, 0.999)`、`eps=1e-8`、`warmup=0`；
- 每 800 个真实优化器更新执行一次原路径 `val/loss`；
- ReduceLROnPlateau：`mode=min`、`threshold_mode=rel`、`threshold=0.01`、`patience=5`、`cooldown=0`、`factor=0.2`、`min_lr=0`；连续第 6 次未达到 1% 相对改善要求时降低学习率；
- 前两次实际降低学习率后继续训练，第三次实际下降时立即停止，不再多执行一次参数更新；
- 每个模型最多执行 40000 个优化器更新；
- best 始终取本次训练中原路径 `val/loss` 数值最低的检查点，调度器第一次 best 来自本次训练的第一次验证；last 保存本次模型、优化器、调度器、下降次数、步数和恢复所需状态。
