**已查明的关键细节：** `IndividualTasksLoss.forward()` 先计算各task与mixed的基础总和，然后把ConfidenceLoss的`cfd_total`仅加到`mixed/total`。可选pocket_dist项也加在`mixed/total`。`ModelLightning.training_step()` 优先取`loss`，无此键时使用`mixed/total`。

所以把训练返回值从`mixed/total`改成`dock/total`，会在该实现中漏掉置信度等追加项。不能因为只训练dock就做这个替换。

各项计算必须保留：

| 项 | 源行为 | 禁止简化 |
|---|---|---|
| node/halfedge | 未归约CE，按fixed/unfixed与task掩码再归约 | 固定化学类型后删除分类头/固定项 |
| pos | XYZ逐元素MSE，按相同掩码平均 | 换成每分子RMSD、额外除N或只用坐标 |
| dist | 相同domain/固定距离掩码定义 | 直接改为所有键或所有pair距离损失 |
| dih | 原tor/dihedral元数据与1-cos定义 | 删除字段或换手写角度差 |
| empty mask | 源代码返回0的规则 | 空项nan、改变分母 |
| size_weighted | 当前配置缺省，源码默认False；仍有既有尺寸归一化代码路径 | 自己加按N加权 |
| confidence | 原ConfidenceLoss实现、detach/target/reduction | 自造成功概率loss或遗漏 |

D3仅追加 $\eta_{\mathrm{seg}}(0.7L_{\mathrm{focal}}+0.3L_{\mathrm{Dice}})$。追加到**真实被反传的总键**，同时保留未追加的原loss日志以验收。

### 2.3 原 dock 噪声

| 字段 | 读取值 |
|---|---|
| noise.dock.reassign_in | True |
| prior.pos.name | allpos |
| prior.pos.pos.name | gaussian_simple |
| prior.pos.pos.sigma_func | sqrt |
| prior.pos.pos.sigma_max | 1.0 |
| level.name | uniform |
| level.min / max | 0.0 / 1.0 |
| transform.dock.free / flexible | 0.999 / 0.001 |

本项目已批准free=1、flexible=0。配置中inactive translation/rotation/torsional参数不等于free路径使用了它们；可保留未激活字段，不为“清理”改变模型。新T1是独立登记的整体位移扩展，不能误启用原flexible路径。

`GaussianExplodePrior.add_noise()`原行为：

```text
noise = 按原sigma规则得到的逐原子高斯
pert  = x + (1-info_level)*noise
from_prior且info_level==0时: pert = noise
info_level==1时: pert = x
```

sqrt尺度使用原 `sigma[:,None].clamp(min=1)`；保留此操作。不要改用名字相近的`gaussian`，后者具有信号衰减，是另一种prior。

T1普通分支新增$s\,(\mathrm{given\_center}-\operatorname{centroid}(\mathrm{clean\_input}))$，训练clean_input为GT，推理重加噪为当前预测；纯先验分支跳过新增平移。给定中心与 clean_input 的质心必须在同一坐标系；中心化后的实现新增项为 $-s\operatorname{centroid}(Z_{local})$，共同旋转后也不能混入世界坐标。源条件/target不改变。$w(s)=s$，不新增径向clip。按同一生成样本验证step/info_level与所有广播维度。

## 4. 实施后的验收与最小产物

这些是后续代码验收要求，当前没有运行或宣称通过。用少量有代表性的非测试输入组成检查组，避免为每个检查制造生产层抽象或逐步文件扫描。

### 4.1 原模型、损失与训练控制

- 关闭新增分支、无核酸且输入/RNG 相同时，核对原模型输出、完整 loss 各叶和参数梯度；不同 microbatch 拆分不要求相互数值等价。
- 核对 frozen node/halfedge 与 free 坐标、空 tor/domain 元数据、原 `reassign_in` 的次序和形状；confidence 不因改用 `dock/total` 而消失。
- 使用可控验证标量检验相对阈值、连续第 4 次坏验证降 LR、前两次继续、第三次下降后零额外 optimizer 更新；恢复后不重置历史。
- 对累积 2／3 的代表配置确认第 1000 个 optimizer update 才验证；多 rank 只完成一次逻辑 scheduler step，各 rank stop 一致。
- OOM 不静默丢训练或验证样本；验证尾部不漏、不重复计分；best／last 标记与中断恢复一致，正式停止的 checkpoint 不自动续训。

### 4.2 平移与受体

- T0/T1 使用相同中心增强和基础高斯。训练新增项在重分配前等于共享 $s\delta$，GT target 不变；推理按当前预测中心差，首个纯先验步不重复加 T。
- 检验 4 Å 只限制中心抽样，不径向裁掉更大的预测中心差；C0 不意外关 T1，s 取实际 info_level。
- 口袋选择使用残基重原子质量中心，阈值为中心 15 Å、包络 10 Å，严格小于；原点按各协议定义，不用密度块中心取代。
- AdaLigand 与原 PXM 的蛋白残基编号必须重排；芳香键不能 `argmax+1`；UNK 不自动当 NA。核酸的 RNA/DNA、修饰母体有来源。
- 官方纯 RNA 不提前跳过；尽可能执行原正常流程，准确区分是否到达 forward 与是否得到可评价输出。报告其 100% 核酸条件、结果／错误和固定分母。

### 4.3 数据、地图与密度

- 实例唯一，候选与 occurrence 绑定；排除列表和保留数量可复算，13 个坏图与 192 个坏 SMILES 不重复计数。
- 完整图与观测子图、缺失坐标、对称排列在同一索引契约中使用；训练不补造 GT，推理不传入删原子提示。
- CAP10/HF10_TO5 在排除后的 ALL 频数上判断，同一排序嵌套；频数 6–10 全留。不同视图复用同一预测及 C4/seed。
- 地图 47/48/大于 48 的边界、非零 origin、非单位／非等轴 spacing、ZYX/XYZ、rint 半整数和实际起点均检验。每轴不足 48 报错，其余直接切 48；不补零／mask，归一化用整块。
- 共同变换配体、受体、体素坐标并用逆变换查原数组；不重新插值地图。裁块内缩后模型原点不变。
- D2 每个原子读取全部邻域并集，D4 只读自身；原子越界取交集，空邻域零残差无 NaN，不能夹边冒充信号。
- 密度门控初值有梯度；D3 标签只针对当前实例、只读预测 top-K；缓存不跨更新复用旧可训练特征。距离偏置等价优化同时比较输出和输入／参数梯度。

### 4.4 正式评价与产物

- 所有方法共用冻结分母与评价核，失败保留；缺失／纯 RNA 等逐实例条件可重算，几何检查失败或不适用不得记作通过。
