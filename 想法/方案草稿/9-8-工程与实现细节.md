## 1. 训练配置与执行语义

当前训练入口只保留中心RA＋T0和包络RA＋T0，分别测试C0/C5及E；密度每个获准配置沿用这两个模型，不新增组合。每实例每协议50候选、100步，训练val/loss不生成候选池。已完成六模型的10个协议组合和30个视图是历史事实，详细数值与实际配置见非密度日志。

### 1.1 固定数值

| 参数 | 当前值或行为 |
|---|---|
| 优化器 | 沿用原 AdamW；初始 lr=1e-4，不重写优化器 |
| 其他 AdamW 参数 | weight_decay=0.001、betas=(0.99,0.999)、eps=1e-8；不建旧／新参数学习率分组 |
| warmup | 0 |
| 名义全局批量 | global_batch_size=72；默认单卡，等于单卡 batch×梯度累积次数 |
| 精度 | bf16-mixed |
| 无密度 batch／累积 | 优先单卡72×1、不梯度累积；显存不足可按 36×2、24×3、18×4、12×6 调整 |
| 密度 batch／累积 | A800预实验当前选择D1为72×1、D4为36×2；D4的72×1反向OOM。必要时成对降低批量并保持global72，D2/D3不外推为已验收 |
| 偶发 OOM | 允许原 reduce_batch 裁掉少量实例后继续，记录发生情况；不增加补样本或 microbatch 归约等价机制 |
| 验证损失 | 每 800 个优化器更新计算一次原路径 `val/loss` |
| Plateau | mode=min、threshold_mode=rel、threshold=0.01、patience=5、cooldown=0 |
| 下降倍率与下限 | factor=0.2、min_lr=0，沿用 scheduler 默认 eps=1e-8 |
| 停止 | 第三次实际下降后、下一次参数更新前停止；同时最多 40000 个优化器更新，先到者生效 |
| 训练随机种子 | 沿用 train.seed=2023，不安排种子或学习率搜索 |
| 原损失与置信度 | 保留全部原计算和真正反传总键 `mixed/total` 内的 confidence |

连续第 6 次验证没有达到 `current < scheduler_best×(1−0.01)` 时才下降；不是只与上一次验证相比。学习率序列为 `1e-4 → 2e-5 → 4e-6 → 8e-7`，第三个箭头触发停止，不在 8e-7 再更新参数。

### 1.2 模型初始化、验证与恢复

新训练只加载官方 pxm 的 `model.*` 参数，重建优化器和训练包装状态，训练全部原主干及新增受体参数。作者 checkpoint 的 optimizer、scheduler、bad_epoch、best、global_step 等训练状态不加载；scheduler 初始 best 来自本次训练第一次验证。RA保留原pocket_encoder参数名，只增加核酸输入投影nucleic_embedder；恢复自身checkpoint不再执行官方初始化。

`utils/train.py::get_scheduler` 已完成threshold等配置接线。原 Lightning 的 `val_check_interval` 计训练 batch，不能把 800 个 microbatch 当作 800 次优化器更新；累积为 2／3 时对应 1600／2400 个 microbatch。每个验证结果只能驱动一次 plateau，不同时由自动配置和回调重复 step。

第三次下降时完成该次调度、记录停止原因并保存状态，在下一次 optimizer step 前结束。40000 恰为 800 的整数倍，到上限时完成对应验证和保存，不执行第 40001 次更新；原 180000／240000 上限不再控制新实验。无限训练 Dataset 与 `max_epochs` 的接线不得提前结束本阶段。

评价使用原 `val/loss` 数值最低的 best；显著改善阈值不改变 best 的数值最低定义。last 用于恢复自己的模型、优化器、scheduler best／坏验证计数、累计下降次数、global_step、主进程 RNG 与已停止标志，并保留实际数据配置和冻结清单路径。多 worker 续训继续按相同 occurrence 均匀有放回分布抽样，不保存预取队列，也不要求中断前后逐样本完全同序。满足正式停止条件的 checkpoint 不通过普通 resume 清零后继续；Slurm 时间结束、手动中断或 OOM 中断均不算训练完成。

每个获准模型的最终best运行一次对应C0/C5/E的完整测试，不再安排完整验证集采样及评价。每800更新的训练验证保留原 `val/loss`、调度和best选择，不生成50条候选。程序正确性验收仅用非测试数据；不能看测试结果后改训练配置或筛选。

### 1.3 OOM、验证覆盖与检查点

无密度 batch 优先尝试72且不累积，必要时依次改为36、24、18、12及相应累积次数；密度当前按上表已实测的D1／D4批量开始。偶发原 `reduce_batch` 少量裁批可以继续，日志据实记录；若反复 OOM，则改用较小单卡 batch 和匹配累积，名义 global batch 仍为 72。不建设丢样本补偿、严格归约等价或频繁中断恢复机制。

原 `utils/dataset.py` 的有限验证迭代器采用 `total_size // total_samplers` 分配数量，可能漏掉尾部。新入口修正正常遍历下的 worker 划分，避免漏样和重复，保留原 loss；偶发 OOM 裁批另据实记录，不把正常覆盖缺陷解释成已允许的 OOM。

原 ModelCheckpoint 使用 `save_top_k=-1`。继续保留定期 checkpoint 并标明 best／last，不擅自改为自动淘汰旧文件；空间占用写入日志，需要清理时另获明确许可。不同模型的配置、目录和 checkpoint 互不覆盖。

`parse/{pdb_id}/ligand_coords.npz` 的 `coords_{cid}` 为 float32 `(M,3)`，`present_{cid}` 为 bool `(M,)`，均与完整模板重原子顺序对齐；缺失位置为 NaN，坐标是世界 XYZ，单位 Å。`centroid_atom_{cid}` 为沉积原子几何中心；通过完整性筛选后它就是完整配体重原子中心。

### 2.5 蛋白与核酸受体特征

完整受体 `receptor_tokens.npz` 有世界 XYZ 坐标、元素、残基／链编号、atom_name 和 res_type，可从完整标准受体重新选口袋。`res_type` 0–19 为标准蛋白，20–23 为 RNA A/C/G/U，24–27 为 DNA DA/DC/DG/DT，28 为 UNK。UNK 原子不入模型或正式碰撞受体，不建立修饰母体映射，不根据旧 feat 的母体映射猜测类别。

AdaLigand 蛋白顺序为 `ALA ARG ASN ASP CYS GLN GLU GLY HIS ILE LEU LYS MET PHE PRO SER THR TRP TYR VAL`；PocketXMol 原顺序为 `ALA CYS ASP GLU PHE GLY HIS ILE LYS LEU MET ASN PRO GLN ARG SER THR VAL TRP TYR`。例如 ARG 从 1 映射到 14，CYS 从 4 映射到 1，不能直接沿用原整数。蛋白 25 维仍为元素 `[C,N,O,S]` 4 维＋原氨基酸 20 维＋backbone 1 维。

核酸特征为 float32 `(N_NA,15)`，`N_NA` 是当前口袋标准核酸重原子数：`[0:4]` 为 `[C,N,O,P]`，`[4:12]` 为 `[A,C,G,U,DA,DC,DG,DT]`，`[12:15]` 为 `[base,sugar,phosphate]`，各段独立 one-hot。糖原子为 `C1'/C2'/C3'/C4'/C5'/O2'/O3'/O4'/O5'`，DNA 无 O2'；磷酸为 `P/OP1/OP2/OP3`，兼容 `O1P/O2P/O3P`；其余合法标准核苷酸重原子为碱基。旧原子名 `*` 机械转换为 `'`，不加入修饰特征或额外 RNA/DNA 标志。

RA独立投影后将蛋白与核酸节点放入同一受体图，进入共享编码器与联合近邻图。空核酸批次保留真实空张量，不造假节点或改变实例抽样。

历史583候选中C0、E各有7个标准核酸邻域；`(9v7o,0,CCD:GMP)`无标准蛋白，完整受体6083原子全部是标准RNA。C0有9个、E有5个选到UNK，不能把这些数当成核酸实例数。完整性筛选与C5冻结偏移后的实际分层已在无密度实验中统计，结果见各实验日志，旧候选数字不直接充当当前分层。曾核对A1CZ2是修饰RNA、A1EQM/LLP是修饰氨基酸；这个事实只说明UNK不能统称核酸，当前统一排除UNK原子。

### 3.5 排名与完整受体检查

原 `self_ranking=cfd_traj+no_clashes+stereo`，两项布尔检查通过各加 1，confidence 轨迹聚合和阈值保持。官方与扩展模型的碰撞辅助检查统一使用完整标准蛋白＋RNA/DNA 受体重原子，排除 UNK、水和辅因子；生成官方仍仅接蛋白。由现有受体资产在内存装配检查器所需字段，不额外写新的受体科学文件。

原两个辅助检查不等于完整 PoseBusters。`buster_tools` 的距离判据依赖元素、PDB 元数据和排除类型，新适配须验证实际接入的受体集合；不能让名称 protein 或 HETATM 默认处理偷偷排除标准核酸／纳入辅因子。只报告实际完成检查，失败或不适用不得写成通过。tuned ranker 不加载、不适配、不补跑。

通过累计数据筛选的纯 RNA 实例仍实际尝试官方原路径。原 `FeaturizePocket` 对空蛋白可能给出 `(0,3)` center，错误可早于 forward；区分输入构造、forward、采样、还原和评价。不要临时填假蛋白、假原点，或把未进入 forward 写成模型前向失败。记录每协议口袋中蛋白／NA 原始重原子数及 `NA/(protein+NA)`；分母为零记 NA。

评价保持原不移动姿态的 `CalcRMS` 对称感知重原子 RMSD，不单独对齐配体。训练 `matches_iso` 考虑的手性置换不能代替评价原匹配。Top-1／Top-5 与全候选 oracle 分开，成功阈值严格 RMSD<2 Å。

新增逐 occurrence Spearman ρ(self_ranking,−RMSD) 和 Pose ROC-AUC，后者以 RMSD<2 Å 为正类、self_ranking 为分数；使用相同有效候选池。Spearman 报 occurrence 等权均值和中位数，AUC 报 occurrence 等权均值，不能混合不同 occurrence 候选。候选不足／恒定输入／单一类别等不可定义情况记 NA，保存原因和有效数量，不能记 0。姿态成功率另保留 occurrence 汇总和 PDB 等权汇总。

## 4. 密度几何与后续构造

### 4.1 直接裁 48 个源体素

`density/{pdb_id}/exp.npy+exp.npz` 和 sim 为 `(1,Z,Y,X)`，origin 是世界 XYZ 边界角点。直接读现有 AdaLigand canonical 资产，不重做 MRC 转换或重采样。真实 XYZ spacing 读元数据，例如历史 9lfa 约 1.000336 Å、9nvn 约 1.001739 Å，不当作 1 Å 常量。

成熟几何位于 [stage1_requests.py](../../../Pocket_Plus/src/datasets/stage1_requests.py) 的 `resolve_stage1_start`、`centered_start_from_centroid_zyx`：先 `np.rint`，后 clip 到 `[0,full_shape-box_shape]`，小于块即报错。本项目显式传 `(48,48,48)`，不用原默认 80。

设请求中心 $Q$、源边界角点 $O$、实际间距 $d$ 都按 XYZ 表示，源空间形状为 $S_{zyx}$，实际起点为：

$$
s_{zyx}=\operatorname{clip}\!\left(\operatorname{rint}\!\left(((Q-O)/d)_{zyx}-24\right),\ 0,\ S_{zyx}-48\right).
$$

先检查任一维小于 48 即报错，否则直接切三轴长度 48。保留 NumPy rint 的半整数行为，不自造 floor／trunc；不补零、不增加有效体素 mask、整块归一化。exp、所用 sim 与当前实例标签使用同一实际起点和源几何。

块内体素索引 $i$、实际起点 $s$ 重排为 XYZ 后：

$$
x_{voxel,model}=O+(s+i+0.5)\odot d-C.
$$

$C$ 沿原模型原点：中心给定中心，包络选定口袋重原子均值。请求中心 $Q$ 在中心训练及val/loss为 $g$，中心评价为实际C0/C5给定中心，E为配体中心。裁块内缩只改变 $s$，不改变 $Q$、$C$ 或先验。此处 $s$ 是裁块起点，不是加噪强度；该定位约定用于后续密度阶段。

共同刚体增强作用于配体、受体和体素坐标，查询时用逆变换回到原 ZYX 数组，不旋转插值密度。D2/D4 的原子邻域越界取与块的交集，空邻域零残差，不夹边伪造密度信号。地图任一维不足48时，密度输入验收记录原错误，不填假块；沿用已有冻结清单，不自动重新筛选、冻结或改变评价分母。若该错误影响正式训练，先报告实例和影响，再确定处理方式。

### 4.2 U-Net、注入与 D3 辅助监督

D1／D4／D2／D3分别为粗体素全局、自身7³邻域、单分子所有原子7³邻域去重并集、预测top4096读出。固定Pocket_Plus的SimpleUnet、56输入通道、planes=[64,256,256,256,256,256,128,64,64]，不加载其训练权重、不加入recycle。D1仅三次下采样到6³及原四层三维旋转位置注意力（八头、每头192维）；必须停止后续计算。D4/D2/D3保留四次下采样及完整解码器，输出48维。D1粗网格j的源中心索引为8j，体素世界位置为O+(s+8j+0.5)*d。

原六个更新块分别在节点更新后、边／坐标更新前注入密度残差；每块独立四头×64维读出，再投影回320维，alpha初始0.1、门控固定1。D2/D4每块使用当前原子位置重新选邻域。全局attention以普通FlashAttention为速度参照，尝试科学契约的非负可学平方距离偏置；输出／梯度验收后，完整更新增时不超过10%才保留，否则正式前统一普通attention。不得跨优化器更新缓存可训练特征；同一次forward共享编码，推理同权重及固定裁块可跨候选和采样步共享编码。

D3概率头输入48维体素特征和冻结768维SMI-TED向量，隐藏宽度64、ReLU后输出两个logits，不加XYZ输入；可将第一层等价拆成两部分线性投影相加，以免为每体素复制768维向量。只读预测top4096，概率并列按ZYX展平索引确定顺序。原loss上追加 `0.1*(0.7*focal+0.3*Dice)`，用当前occurrence标签监督全块。复用[原损失配置](../../../Pocket_Plus/configs/loss/stage1_unet_c1.yaml)和[损失实现](../../../Pocket_Plus/src/modules/losses.py)：二logits softmax，gamma=2，类别权重0.5／0.5，全块体素平均；Tversky两误差系数0.5，前景在批次和空间维归约，smooth=1，MSE零。辅助损失单列，best及调度仍用原dock的val/loss。

### 4.3 56 通道与 SMI-TED 来源

[density_channel_builder.py](../../../Pocket_Plus/src/datasets/density_channel_builder.py) 的通道顺序是运算外层、归一化中层、后处理内层：`OPS=[exp,sim,diff,posdiff]`，`NORMS=[nonorm,clipnorm]`，`POSTS=[nopost,gauss1,gauss2,DoG1,DoG2,smooth1,smooth2]`，共 56 通道。diff=exp−(a×sim+b)，posdiff=max(diff,0)，DoG 为 G(1.6σ)−G(σ)。高斯 reflect 边界，clipnorm 用 0.001／0.999 分位后标准化，smooth 与差图拟合使用受体区域掩码；该掩码不是边界有效体素掩码。拟合样本或 sim 方差不足的成熟回退保持 a=1、b=0。

56通道先裁48³再计算，不能完整地图构造后裁剪，因为分位、尺度拟合和边界后处理不同。nonorm保持原值；clipnorm截断后按整个块的均值和std+1e-8标准化，不再次统一归一化56通道。受体mask使用完整源receptor_tokens中的坐标，包括UNK，按floor落入块内体素，不按口袋缩小、不膨胀范德华球、不读GT配体标签；smooth半径为2体素。RA原子图仍排除UNK。

通道构造保持Pocket_Plus原模块，使用启用全部通道的配置（源码字面值为`enabled_channels=["all"]`）。不为缩短代码或减少配置分支而精简；只有实测表明可以加快构造速度时才作针对性优化，并核对56通道数值不变。

完整裁块无零填充，通道函数不增加valid_mask。历史9lfa sim元数据为Chimera 1.19、strict_hetatm_removed=true，仅含所选模型ATOM重原子，可能漏修饰聚合物；披露源覆盖限制，不重建模拟资产。Pocket_Plus I/O只作参考，不强制复制整套加载结构。

现有 SMI-TED 根为 `/storage/penghongen/AdaLigand/Ori_Data/stage1_preparation_box_pool_2/ligand_language_models/smi_ted_289m`，权重根为 `/storage/penghongen/AdaLigand/model_weights/ligand_language_models/models/smi_ted_289m/`，含 smi-ted-Light_40.pt、bert_vocab_curated.txt 与冻结源码；runtime 在同权重总根的 `runtime/smi_ted_289m/`。

[表征产物说明](../../../AdaLigand/Data_Preprocessing/Ori_Data_upgrade/ligand_language_model/README.md)规定 SMI-TED Light 289M、float32 `(768,)`、202 token 截断，输入为 canonical non-isomeric 字符串，不声称文本保留全部手性。身份、prepared_smiles、model_smiles 和向量需对应。历史覆盖记录含失败，不能把总数当可用数；失败直接排除，不补向量。SMI-TED 仅为既定 D3 概率头的条件，不扩充无密度模型。

### 6.3 CPU 与 GPU 调度
