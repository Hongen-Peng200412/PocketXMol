本文规定科学任务、模型候选、实验编号、比较协议和执行标准。当前状态为**规划定稿**；各项模型扩展和实验须按本文编号分别实施，完成情况由对应执行记录维护。

文档位置（仓库相对路径）：`想法/方案草稿/9-7.md`。科学讨论来源为[规划 PocketXMol 扩展](chatgpt-conversation://6a9e2e35-243c-83ee-841e-eb05d122b217)；本文完整记录当前采用的决策，不要求读者依赖原讨论理解实验定义。

## 1. 研究目标与已经确定的路线

研究任务是：给定小分子的化学图、粗略 docking 中心、固定的蛋白质与核酸受体结构，以及同一坐标系下的实验 cryo-EM 密度图，预测小分子的三维姿态。docking 在本文中指将已知化学结构的小分子放置到受体结合区域；cryo-EM 指冷冻电子显微镜。

主要检验三个问题：

1. **实验密度的增益**：在数据、口袋定义、训练预算、候选数量和排序协议匹配时，实验密度是否改善 PocketXMol 式坐标去噪。
2. **密度读取方式的差异**：全局粗体素、局部邻域、邻域并集和监督选择的稀疏体素，分别适合什么情况。局部——全局的密度信息注入是否有额外的效用。
3. **条件迭代的作用**：根据第一阶段预测重新选择口袋、重新裁剪密度或初始化坐标，是否改善最终结果。

主训练与评测仅包含普通非共价小分子。蛋白质与(非HETATM)核酸共同构成受体条件；核酸结果作为分层评测，不要求单独建立核酸专用的大规模预训练体系。

固定配体原子类型、键类型和受体坐标，仅对配体坐标使用逐原子自由位置噪声。首版不加入步间刚体投影、扭转扩散、受体柔性或外部能量梯度引导。FFT 定位和 stage1-Find 实现不属于本计划；前者指基于快速傅里叶变换的定位，后者指已有项目中从密度定位配体的阶段。

实验顺序确定为：

> 无密度基线 → D1 全局粗体素 → D4 原子局部邻域 → D2 邻域并集与 D3 监督 top-K → 按结果选择局部与全局联合注入。实际操作中，可以在服务器中同时提交多个任务，如果全集训练时间较长，可以固定一个小数据集进行训练。

top-K 指按预测分数保留最高的 K 个体素。两阶段采样的第一轮实验同时比较完全重启与部分重新加噪。受体编码 A/B 均保留，默认先实现分别编码的 B。

### 2.3 样本与原子对应关系

主集要求来源类别为 `small_molecule`，即普通小分子；未与受体共价连接、完整化学模板有效，且沉积原子能映射到模板。原子和键必须能由选定的 PocketXMol 输入词表表示。

一个样本对应指定密度资产中的一个配体实例。实例身份使用 `(pdb_id, candidate_id)`；例如 `("7d3f", 4)`。语言模型资产中的 `candidate_id` 对应该实例编号，不能用化学对象名称代替实例身份。

每个样本至少保存：

| 内容 | 数据含义 |
|---|---|
| 完整化学模板 | 全部重原子、键、原子顺序和立体化学 |
| `observed_mask` | 长度为模板原子数的布尔数组；`True` 表示存在沉积坐标 |
| `obs_to_template` | 每个沉积原子在完整模板中的索引，使用从 0 开始的编号 |
| 沉积坐标 | 形状为 `(N_obs, 3)`，`N_obs` 是观测原子数；世界坐标 XYZ，单位 Å |
| 完整受体引用 | 可重新选择蛋白质与核酸残基的完整原子表 |
| 密度引用与几何 | 实验图、原点、体素间距、轴顺序及来源身份 |

例如，五个模板原子只有第 `0、2、3` 个存在坐标，则以下构造示例表示三枚观测原子：

```text
observed_mask = [True, False, True, True, False]
obs_to_template = [0, 2, 3]
```

训练图只包含有沉积坐标的原子，其特征和键由完整模板按索引提取。训练加噪及位置损失不需要缺失坐标掩码，也不为缺失原子伪造位置。

推理使用完整化学图。评价时在允许的化学对称映射下，仅比较参考结构中实际存在的原子；不对配体单独进行刚体对齐。完整预测分子的几何检查仍覆盖全部预测原子。


### 2.4 中心增强、口袋与坐标系

本文将沉积的参考姿态记为 GT，即 ground truth。设沉积配体观测原子的质心为 $c_{\mathrm{GT}}$，模型得到的粗中心为：

$$
\tilde c=c_{\mathrm{GT}}+\epsilon_c.
$$

默认中心扰动 $\epsilon_c$ 在半径 **6 Å 的球体内按体积均匀采样**，与配体坐标噪声独立。训练时重新采样；主评测为每个实例固定同一扰动，供所有方法共享。

受体仅包含固定的蛋白质和核酸聚合物原子。两种口袋都保留被选中残基的全部重原子：

$$
R_C(\tilde c)=\{r:\|\operatorname{COM}(r)-\tilde c\|<15\ \text{Å}\},
$$

$$
R_E(Z)=\{r:\min_i\|\operatorname{COM}(r)-Z_i\|<10\ \text{Å}\}.
$$

$r$ 遍历完整受体中的残基；$\operatorname{COM}(r)$ 是残基重原子的质量中心；$Z_i$ 是定义包络的配体原子坐标。$R_C$ 按中心距离选择残基，$R_E$ 按配体包络选择残基，选中后再展开为完整残基重原子。该包络判据沿用当前 PocketXMol 默认的残基质心判据。

训练 GT 包络模型 $M_E^{GT}$ 时用沉积配体定义 $Z$；部署时用上一阶段预测定义 $Z$。所有重选操作从完整受体开始，不能从第一阶段已经裁剪的口袋继续裁剪。

单次去噪轨迹内固定口袋成员。默认局部原点显式绑定到本轮给定中心，不再隐式改成所选口袋原子的均值。

### 2.5 密度空间与增强

默认网络密度网格为 **48³、1 Å 间距**。源图实际间距用于物理坐标重采样，不能直接把源数组索引当作 Å。

源图原点是网格外边界的下角点；体素中心为：

$$
p=o+(i_{xyz}+0.5)\odot\Delta.
$$

$p$ 是体素中心的世界坐标，$o$ 是源图原点，$i_{xyz}$ 是从 0 开始的 XYZ 体素索引，$\Delta$ 是各轴体素间距，$\odot$ 表示逐元素相乘。$o$、$\Delta$ 按 XYZ 排列，数组存储按 ZYX 排列。例如 $o=(10,20,30)$ Å、$\Delta=(1,1,1)$ Å、$i_{xyz}=(0,0,0)$ 时，$p=(10.5,20.5,30.5)$ Å。

蛋白质、核酸、配体、密度及监督区域共同进行旋转和平移变换。

主输入使用 `exp_clipnorm_nopost`，即截断并标准化、无空间后处理的实验密度：先取得当前密度块，再按块内的 0.1% 与 99.9% 分位数截断，随后减均值并除以标准差加 $10^{-8}$。源图外的体素具有独立有效性掩码，不作为真实密度参与统计和读取。

保留配体部分超出密度块的样本，报告覆盖率。64³ 是独立消融；受体口袋半径与密度块大小分别设置。

## 3. 模型接口和四种密度读取方式

### 3.1 受体编码

| 编号 | 编码方式 | 初始化 |
|---|---|---|
| RA | 蛋白质、核酸分别投影，随后进入共享受体编码器 | 蛋白质兼容权重来自原检查点；新增输入投影单独初始化 |
| RB，默认 | 蛋白质、核酸分别投影和编码，编码后合并为统一受体条件 | 核酸编码器复制原口袋编码器的兼容权重，随后独立训练 |

蛋白质保留原有输入特征。核酸输入至少明确表示元素、标准碱基类别、RNA/DNA 类别、主链标记及修饰标记；修饰核苷酸保留其真实重原子。

初始版本使用统一的配体—受体几何近邻。按受体类型分配近邻名额属于单独实验，不作为主模型默认。

需要分别验证：

- 权重能否兼容加载；
- 相同输入下，关闭新增分支能否恢复原模型计算；
- 新口袋和新数据下，模型表现是否保持。

三者不能互相替代。

### 3.2 密度编码器与读取集合

执行默认值为三层三维卷积编码器，通道数 `32、64、128`，下采样两次。完整 U-Net 使用对称解码器和跳跃连接，输出 64 维体素特征。注意力采用 4 个头，每头 64 维，输出投影到配体节点维度。

这些是首轮实现默认值，不是已证明最优的结构参数。

| 编号 | 密度编码 | 每个配体原子读取哪些体素 |
|---|---|---|
| D1 | 仅编码器，48³ 下采样到 12³ | 全部 1728 个粗体素 |
| D2 | 完整 U-Net | 所有配体原子 home 体素的 7³ 邻域并集 |
| D3 | 完整 U-Net 及目标配体概率头 | 预测概率最高的 512 个有效体素 |
| D4 | 完整 U-Net | 当前原子自身 home 体素周围的 7³ 邻域 |

home 体素指按物理坐标落入的整数体素。D2 中每个原子读取整个并集；D4 中每个原子只读取自己的邻域。

D2、D4 在每次注入前依据当前坐标更新读取集合。体素索引去重并按固定顺序排列；越界邻域与有效网格取交集，不能把越界坐标钳制到边缘。空集合返回零密度残差。

D1 和 D3 的读取集合在一次固定密度条件下可以缓存。推理时密度编码结果可在同一密度块的多个候选间复用；改变密度裁剪后重新编码。

### 3.3 D3 的语言模型条件与监督

D3 默认复用冻结的 SMI-TED 表示。已核实的资产根目录是：

`/storage/penghongen/AdaLigand/Ori_Data/stage1_preparation_box_pool_2/ligand_language_models/smi_ted_289m`

其中每个实例文件的 `embedding` 为 `float32 (768,)`，表示一个配体实例的 768 维化学向量。数据准备核对实例身份、SMILES 来源、模型版本和数值有限性；SMILES 是化学图的线性字符串表示。SMI-TED 表示是化学条件，不提供原子坐标或原子对应关系。[SMI-TED 官方资料](https://research.ibm.com/publications/smi-ted-a-large-scale-foundation-model-for-materials-and-chemistry)

默认只把该向量接入 D3 概率头，不自动接入其他读取方式。概率头同时读取体素特征及其相对粗中心的位置。

监督目标是**当前目标实例**观测原子的范德华体积区域。其他配体实例不是当前目标的正标签。标签可由坐标现场构造，不要求每次额外加载监督 NPZ。

训练始终使用预测 top-K，不把 GT top-K 输入主去噪器。硬 top-K 的选择头通过辅助损失训练：

$$
L_{\mathrm{seg}}=L_{\mathrm{BCE}}+L_{\mathrm{Dice}},\qquad
L=L_{\mathrm{pose}}+L_{\mathrm{confidence}}+0.1L_{\mathrm{seg}}.
$$

$L_{\mathrm{seg}}$ 是体素区域监督损失；$L_{\mathrm{BCE}}$ 是二元交叉熵损失，$L_{\mathrm{Dice}}$ 是区域重叠损失；$L_{\mathrm{pose}}$ 是位置监督损失，$L_{\mathrm{confidence}}$ 是位置置信度辅助损失。

BCE 使用按当前样本正负体素数量确定、上限为 100 的正类权重。空前景样本计算背景 BCE，并避免 Dice 分母为零。

D3 的无语言模型对照只去掉语言向量。D2、D4 的同监督对照增加相同概率头和辅助损失，但不使用该头选择体素。

同一化学配体在局部区域出现多个副本时，主指标仍按指定实例计算，另外报告身份相同且定位区域重叠的歧义样本。

### 3.4 特征注入与门控

denoiser 是预测去噪后配体坐标的网络，block 是其中一次节点、边及坐标更新的计算单元。密度残差接在每个 denoiser block 的节点更新之后、边和坐标更新之前：

$$
h_i^{(\ell)}
\leftarrow
h_i^{(\ell)}
+\alpha_\ell g_\ell(s)\Delta h_i^{(\ell)}.
$$

$h_i^{(\ell)}$ 是第 $\ell$ 个 block 中配体原子 $i$ 的特征，$\Delta h_i^{(\ell)}$ 是密度分支产生的特征增量；$\alpha_\ell$ 为可学习标量；$s$ 表示实际施加的归一化位置噪声强度，0 表示无噪声，1 表示原噪声计划对该分子定义的最大强度。

默认每个 block 的 $\alpha_\ell=0.01$，$g_\ell(s)=1$，密度输出投影正常初始化。不得同时把残差输出和门控都初始化为零。

第一版通过特征影响原坐标更新器。额外密度坐标分支另做消融，不把特征注入描述为“完全不影响坐标”。

噪声元数据必须在模型前向之前写入，同时提供归一化强度和实际 Å 标准差。当前采样代码在模型前向之后写入的 `step` 不能直接承担这个接口。

### 3.5 空间偏置与加速

默认注意力分数为：

$$
a_{ij}
=\frac{q_i^\top k_j}{\sqrt d}
-\lambda\left\|\frac{x_i-p_j}{10\ \text{Å}}\right\|^2,
\qquad \lambda=\operatorname{softplus}(\beta).
$$

$q_i$ 是配体原子 $i$ 的查询向量，$k_j$ 是密度体素 $j$ 的键向量，$d=64$ 为单头维度；$x_i$、$p_j$ 是同一坐标系下的原子与体素中心位置，单位 Å。$a_{ij}$ 是归一化前的注意力分数；可训练参数 $\beta$ 经 softplus 映射得到正的距离权重 $\lambda$。

每个头分别学习 $\lambda$，初始值为 1。平方距离项可通过扩充查询和键实现，避免显式构造完整距离偏置矩阵；扩充后必须显式控制注意力缩放，并验证输出及参数梯度。

FlashAttention 的 ALiBi 使用序列索引距离，不能直接代替三维几何距离。其他几何偏置如需使用 FlexAttention，应作为明确的实现变体，记录硬件和性能。[FlashAttention 官方实现](https://github.com/Dao-AILab/flash-attention)、[FlexAttention 可学习偏置支持](https://pytorch.org/blog/flexattention-for-inference/)

### 4.4 三通道与 56 通道的精确定义

现有配方来源：

`/home/penghongen/My_Project/Pocket_Plus/src/datasets/density_channel_builder.py`

输入消融绑定该生成器的已核实版本。实施时记录源文件校验值并建立本项目内的明确依赖，不依赖另一个项目目录的隐式导入。

56 通道按以下顺序展开：

```text
运算：[exp, sim, diff, posdiff]
归一化：[nonorm, clipnorm]
后处理：[nopost, gauss1, gauss2, DoG1, DoG2, smooth1, smooth2]
```

先遍历运算，再遍历归一化，最后遍历后处理。例如第一个通道为 `exp_nonorm_nopost`，最后一个为 `posdiff_clipnorm_smooth2`。

- `exp` 是实验密度，`sim` 是受体模拟密度。
- `diff = exp - (a·sim+b)`；`a、b` 分别是比例系数和常数偏移，沿用现有高密度区域最小二乘拟合。
- `posdiff = max(diff,0)`。
- `nonorm` 保留该运算结果，`clipnorm` 使用 0.1%—99.9% 截断后标准化。
- `nopost` 不进行空间后处理。
- `gauss1/2` 使用标准差 1、2 个体素的高斯滤波。
- `DoGσ = G(1.6σ)-G(σ)`，其中 `G(σ)` 表示对该通道进行标准差为 `σ` 的高斯滤波。
- `smooth1/2` 是按受体距离衰减密度：距离受体 home 体素超过 2 个体素后不再抑制；它不是普通高斯平滑。

三通道固定为 `exp_clipnorm_nopost`、`sim_clipnorm_nopost`、`diff_clipnorm_nopost`。

模拟图与受体掩码均由推理时可得到的完整受体构造，不使用目标配体 GT。执行记录保存展开后的全部通道名称。

## 5. 两阶段采样与统一排序

### 5.1 第一轮迭代实验

默认第一阶段使用 `T-C-D1`；包络模型使用 `T-E-D1` 及其适配版本。密度方式可显式替换，但同一比较组保持一致。

先生成 25 个第一阶段候选。按统一无密度评分器选择 5 个父候选，优先保留对称修正后相距至少 1 Å 的姿态；不足 5 个时按分数补齐。父候选指第一阶段中用于构造第二阶段条件的姿态；第二阶段由该条件产生的姿态称为子候选。

| 实验编号 | 第二阶段受体 | 第二阶段密度与局部原点 |
|---|---|---|
| `I-C-SAME` | 原中心口袋 | 保持第一阶段条件 |
| `I-C-RECENTER` | 以父姿态质心重新选择中心口袋 | 密度和原点同步移到父姿态质心 |
| `I-E-POCKET` | 由父姿态定义包络，使用 GT 包络模型 | 保持第一阶段密度及原点 |
| `I-E-RECENTER` | 由父姿态定义包络，使用 GT 包络模型 | 密度和原点移到父姿态质心 |
| `I-A-POCKET` | 父姿态包络，使用适配模型 | 保持第一阶段密度及原点 |
| `I-A-RECENTER` | 父姿态包络，使用适配模型 | 密度和原点移到父姿态质心 |

`I-C-RECENTER` 是用户选定的重要对照：它直接检验同时更新中心口袋与密度中心是否有效。

`I-E-POCKET` 检验固定密度条件下更换口袋的作用。`I-E-RECENTER` 与 `I-C-RECENTER` 比较时，两者使用相同父候选、密度中心和采样初始化规则。

所有实验保留第一阶段候选，与第二阶段候选一起排序；不假定第二阶段一定改善结果。

### 5.2 完全重启与部分重新加噪

上表每个实验生成以下三个独立采样配置：

| 后缀 | 每个父候选的子候选数 | 第二阶段初始化 | 每个子候选前向次数 |
|---|---:|---|---:|
| `FULL` | 5 | 从本轮中心对应的自由位置先验重启 | 100 |
| `WARM` | 5 | 对父姿态按原噪声规则重新加噪 | 原 100 步计划的后 50 次 |
| `WARM-BUDGET` | 10 | 与 `WARM` 相同 | 50 |

例如 `I-E-POCKET-WARM` 表示仅更新包络口袋、保持原密度与原点，并对父姿态重新加噪后执行最后 50 次去噪前向。

`WARM` 使用所选起始位置实际对应的噪声等级，不能把“后 50 步”直接解释成“噪声标准差减半”，也不能误触发纯先验初始化。

按单候选前向次数累计：

- 单阶段 50 个候选：5,000 次。
- 两阶段 `FULL`：5,000 次。
- 两阶段 `WARM`：3,750 次。
- 两阶段 `WARM-BUDGET`：5,000 次。

`FULL` 与 `WARM` 比较相同候选数量；`FULL` 与 `WARM-BUDGET` 比较相同去噪前向预算。实际 GPU 时间另外统计，包含密度编码、重裁剪和排序。

### 5.3 统一评分器

先实现“共用评分器＋密度拟合分数”，后续再比较联合密度排序网络。

`R-SHARED` 复用 PocketXMol 独立重评分思路，使用固定的无密度模型副本和统一评分头。所有候选均在最初粗中心定义的同一受体条件下评分，不使用各生成模型自己的置信度混排。

评分头在训练集候选上训练，输入为候选姿态，标签为该输入姿态是否达到对称修正 RMSD 小于 2 Å。RMSD 指配体对应重原子坐标差的均方根距离；对称修正只允许化学等价的原子置换，不进行配体刚体对齐。候选池固定由 `T-C-D0` 和 `T-C-D1` 等量生成；模型选择不使用测试集。完整观测样本另外提供小幅扰动 GT 与明显平移姿态，以保证存在正负例。

评分时不对输出姿态执行坐标更新。设共同姿态置信度为 $q\in[0,1]$：

$$
S_0=q+\mathbb{1}_{\mathrm{无严重碰撞}}
+\mathbb{1}_{\mathrm{立体化学一致}}.
$$

$S_0$ 是不读取密度的排序分数；$\mathbb{1}$ 是条件成立时取 1、否则取 0 的指示函数。

密度评分使用预测配体生成的高斯密度与实验图的局部归一化相关系数。高斯宽度默认取地图名义分辨率除以 2.355；在同一化合物的所有候选中固定。越出源图的比例形成显式覆盖惩罚，常量密度区域记录为无可用相关信号。

$$
S_1=S_0+wS_{\mathrm{density}}.
$$

$S_{\mathrm{density}}$ 是包含覆盖惩罚的密度拟合分数，$w$ 是其组合权重，$S_1$ 是使用密度的排序分数。

$w$ 在校准集上从 `{0, 0.25, 0.5, 1, 2}` 中选择，以联合姿态成功指标最大为准；并列时选较小权重。随后锁定评分器与权重。

联合读取受体、配体和密度的排序网络登记为 `R-JOINT`。它是后续独立实验，使用同一候选训练池，并配备不读取密度的对应模型。

### 5.4 四格归因与完整系统结果

每个密度模型都报告：

| 候选生成网络 | 使用 $S_0$ 排序 | 使用 $S_1$ 排序 |
|---|---|---|
| 不读取密度 | 结构基线 | 密度仅用于排序 |
| 读取密度 | 密度用于去噪 | 完整密度系统 |

候选生成后缓存，同一候选池分别使用两种分数排序。

核心迭代实验的父候选统一使用 $S_0$ 选择，保证密度排序因素不会隐含进入候选生成过程。父候选改用 $S_1$ 的系统优化登记为单独的 `X-PARENT-DENSITY`，需要重新生成后续候选。

## 6. 训练、评测与时间配额

### 6.1 统一训练默认值

| 项目 | 默认值 |
|---|---|
| 训练任务 | 仅自由坐标去噪 docking |
| 优化器 | AdamW |
| 预训练参数学习率 | $10^{-5}$ |
| 新增参数学习率 | $10^{-4}$ |
| 权重衰减 | $10^{-4}$ |
| 有效批量 | 每次更新 32 个实例 |
| 学习率计划 | 1,000 次更新预热，随后按 100,000 次更新的余弦计划下降到初始值的 10% |
| 梯度范数上限 | 5 |
| 短程筛选 | 20,000 次更新，种子 3407 |
| 正式确认 | 100,000 次更新，种子 3407、3408、3409 |
| 检查点 | 每 500 次更新及预算停止前保存 |
| 主采样 | 原自由噪声计划，100 次前向，50 个候选 |

训练按 PDB 均匀取样，再在该 PDB 的有效实例中取样，避免少数重复实例很多的结构主导训练。

微批量是单次前向实际处理的实例数，按显存测量确定；通过梯度累积保持有效批量不变。不同读取方式比较相同优化器更新数、样本抽样规则和训练初始化，并同时报告实际计算成本。

短程筛选是正式训练的可续接前缀，不另设一套无法续接的短学习率计划。适配实验使用独立的 10,000 次更新续训计划。

### 6.2 模型选择与主指标

模型和超参数只在验证集上选择。默认按“Top-1 对称修正 RMSD 小于 2 Å 且通过几何有效性检查”的成功率排序；并列时优先选择实际 GPU 推理时间较低者。Top-1 指排序第一的候选，Top-5 指排序前五个候选中至少一个成功。

主评测同时提供：

- Top-1 RMSD 小于 2 Å 成功率；
- Top-1 同时满足 RMSD 与几何有效性的成功率；
- Top-5 成功率；
- 全部候选中的最佳 RMSD 与成功率；
- 密度拟合、受体碰撞及立体化学结果；
- 每实例、每 PDB 的运行时间和显存。

几何有效性采用固定版本的 PoseBusters 检查，并核对受体相互作用检查是否正确覆盖核酸；不把未支持的检查默认记为通过。[PoseBusters](https://pmc.ncbi.nlm.nih.gov/articles/PMC10901501/)

以 PDB 等权汇总作为主要统计，同时报告实例级汇总。比较使用相同中心扰动与采样种子，并按共享 PDB/EMDB 分组计算配对置信区间。

需要分层报告：

- 蛋白质、核酸及混合受体条件；
- 配体与核酸原子的实际接近程度；
- 密度覆盖充分与不足；
- 完整观测与部分原子缺失；
- 地图分辨率；
- 同化学身份的多实例歧义。

迭代实验额外报告第一阶段失败而最终成功、第一阶段成功而最终失败的比例。

Q-score 等局部密度质量指标可作为补充分析；有半图时再开展过拟合相关检查，不将半图作为主集必需输入。Q-score 评价原子附近的密度可分辨性；半图指从独立数据子集重建的两张密度图。[Q-score](https://www.nature.com/articles/s41592-020-0731-1)、[FSC-Q](https://www.nature.com/articles/s41467-020-20295-w)

### 6.3 密度作用的诊断实验

增加 `DIAG-MAP`：在固定已训练模型上比较正确密度、关闭密度残差以及平移 8 Å 的错位密度。平移方向由固定种子确定。

这些结果用于诊断模型是否依赖空间对应的密度。关闭分支或错位输入属于分布改变，不能替代重新训练的无密度基线，也不能独自证明因果贡献。

### 6.4 按预算执行

开发预算与服务器计算预算分别记录。服务器排队时间、实际作业墙钟时间、GPU 数量与 GPU 小时分开统计。GPU 小时等于占用的 GPU 数量乘以实际占用小时数。

每个实验具有以下状态：

| 状态 | 含义 |
|---|---|
| `registered` | 已有完整定义，代码或依赖尚未就绪 |
| `ready` | 实现、输入与必要验证完成，可以运行 |
| `running` | 正在执行 |
| `paused_budget` | 因预算结束暂停，保留可恢复状态 |
| `screened` | 短程训练及对应验证完整完成 |
| `confirmed` | 正式训练、锁定评测和比较报告完整完成 |
| `failed` | 运行或验收失败，保留原因和证据 |

例如，`T-C-D4` 完成 12,000 次更新后因预算停止，其状态为 `paused_budget`；完成 20,000 次更新及对应验证后才可记为 `screened`。

用户可以直接指定实验编号、开发时间和计算时间，例如：

```text
实现 T-C-D4，开发预算 2 小时；
服务器预算另给 8 GPU 小时；
优先完成短程筛选，预算不足时保存进度。
```

执行器先展开实验依赖、估算成本，再推进可完成部分。预算停止不改变实验的训练步数定义，不把部分结果标成正式完成。恢复时加载模型、优化器、学习率计划、随机数状态和数据抽样进度。

实际运行遵守本项目服务器提交与资源占用规则；计划书定稿本身不提交作业。

## 7. 实现顺序、产物与验收

### 7.1 实现顺序

1. **数据与空间接口**：完成 `P0-DATA`，固定测试名单、原子映射、完整受体访问和共同增强。
2. **原模型恢复与受体扩展**：完成 `P1-RESTORE`、RB，以及中心和包络两种口袋构造。
3. **基础实验入口**：建立实验注册表、配置展开、训练恢复、候选缓存与评价接口，运行 `T-C-D0`。
4. **密度模块**：依次实现 D1、D4、D2、D3；D3 默认接入冻结的 SMI-TED。
5. **排序与两阶段采样**：建立共同评分器；实现表中全部迭代条件及三种初始化预算配置。
6. **后续实验**：按指定编号执行编码、通道、门控、坐标分支和联合注入消融。

现有代码中需要对接的关键位置是：模型输入与受体编码、denoiser block 内的密度残差，以及模型前向之前的实际噪声元数据。实现保持这三个职责清晰，不把密度裁剪、文件加载和模型计算混入一个模块。

### 7.2 新接口的最小要求

数据到模型的接口新增：

- 统一受体的类别、原子特征、坐标及批归属；
- 密度数组、有效体素掩码和空间变换；
- 实际噪声强度；
- D3 使用的配体语言向量及训练期实例监督。

外层采样接口新增：

- 从完整受体按中心或预测姿态重新选择口袋；
- 按指定中心重新获取密度；
- 从纯先验或指定姿态重新加噪启动；
- 保存父候选、子候选与完整采样来源。

实验执行接口至少能按编号完成配置展开、依赖检查、训练、恢复、采样、重评分和报告。新入口在实现前标为规划接口，不把尚不存在的命令写成已经可运行。

### 7.3 必须通过的验收

| 验收对象 | 关键场景 |
|---|---|
| 检查点恢复 | 相同输入、无核酸、关闭密度时恢复原模型输出；不把改变口袋后的表现当作函数恢复测试 |
| 空间变换 | 非零原点、非单位源间距、XYZ/ZYX 转换、半体素中心及共同旋转 |
| 动态口袋 | 第二阶段能够取回初始口袋外的受体原子；单次轨迹内成员固定 |
| 密度集合 | D2 并集去重、D4 原子局部限制、越界和空邻域 |
| 注意力 | 扩充查询/键与显式平方距离偏置的输出、梯度一致 |
| 梯度接入 | 小门控下新增密度分支确实收到非零梯度 |
| D3 | 目标实例标签正确；训练与推理都使用预测 top-K；语言向量身份匹配 |
| 采样 | 完全重启与重新加噪语义正确，前向次数与预算统计一致 |
| 原子评价 | 对称配体、部分观测原子、不进行配体刚体对齐 |
| 数据隔离 | 测试结构及共享密度图不进入训练、验证和校准 |
| 恢复运行 | 中断后恢复优化器、抽样进度及随机状态，结果在规定数值容差内一致 |
| 真实样本闭环 | 蛋白质、核酸相关、缺失原子及密度覆盖不足样本均完成加载、训练前向、采样和评价 |

### 7.4 实验交付物

每次运行保存完整展开配置、代码和检查点版本、数据清单版本、训练状态、预测姿态、原子对应关系、两套排序分数、逐实例指标及计算成本。

计划书保持为当前实验规格。逐次运行过程与失败原因进入独立执行记录；映射索引连接实验编号、实现位置、执行记录和完成状态。

最终可以按实验编号回答：使用了什么条件、改变了哪个因素、与谁比较、是否完整执行，以及证据存放在哪里。
